## Собственный проект

Тема проекта: Оружия

Главный класс: Weapon

Почему этот объект нужен программе:

- Класс Weapon может хранить оружия героев из гильдии

Какие данные хранит объект:

- Имя оружия
- Тип оружия
- Урон оружия
- Прочность оружия

Какие значения задаются через конструктор:

- Имя
- тип
- урон

Какие значения можно задавать автоматически:

- Прочность

#### Какое значение я решил задавать автоматически и почему?

Значение Прочности задается автоматически при создании нового оружия. По умолчанию прочность равна 1, при этом минимальная прочность - 0.

## Самостоятельная №2

#### Какие пять методов появились:

- TakeDamage - получение урона
- Heal - восстановление здоровья
- GainExperience - получение xp
- IsAlive - жив ли персонаж
- GetInfo - вся информация о персонаже

#### Как проверили недопустимый урон:

Проверили через 2 условия:

- Отсекаем отрицательные значения чтобы не восстанавливать здоровье уроном
- Восстанавливаем здоровье до 0, если оно уходит в отрицательную зону
